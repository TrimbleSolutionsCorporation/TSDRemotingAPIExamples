# Release notes

This document contains the notes for individual releases of the _TeklaStructuralDesigner.RemotingAPI_ NuGet package for major version 26.

## Version 26.3.0

* Added interface `IMeshingSettings` that encapsulates meshing options used for meshing of slabs and semi-rigid diaphragms.
  * Added property `MeshingSettings` to `ISubmodel`.
  * Marking meshing related properties obsolete and scheduling their removal in version 28.0.0.
* New interfaces `ISectionMaterial` and `ISectionConcrete` have been added that represent the material of a section.
  * To obtain the instances of these interfaces, use the static properties of the `SectionMaterials` class.
  * The information about the section material is now accessed through a new `ISection.Material` property.
  * A new set of methods has been added to `ISectionFactory` that use the `ISectionMaterial` interface to create sections (the previous methods used `MaterialType` enumeration).
  * The `ISection.MaterialType` property as well as the original methods for creation of parametric sections in `ISectionFactory` have been marked as obsolete and will be removed in version 28.0.0.
* Support for joist girder sections management has been added.
  * A new method `ISectionFactory.CreateJoistGirderSectionAsync` has been added to create joist girder sections.
  * A new method `ISectionFactory.GetJoistGirderSectionsAsync` has been added to retrieve all joist girder sections.

## Version 26.2.0

* A bug causing the `MemberSpanInfo` to fail to identify the correct member span in some cases has been fixed.
* The method `IDesignCondition.GetResult` has been made obsolete and will be removed in version 28.0.0.
  * The method always returned either `CheckStatus.Pass` or `CheckStatus.Fail` and did not provide any additional information.
  * The recommended alternative is to use the `IDesignCondition.GetStatus` and check for `DesignStatus.Actual` (or `DesignStatus.Failed` respectively).
* A new method `ILoadcase.GetGeneratedWindDataAsync` has been added that allows users to retrieve the generated wind data for a loadcase.

## Version 26.1.0

There are no changes in this version.

## Version 26.0.0

* The type of the property `MinorAxisElasticSectionModulus` of `IColdRolledSectionBase` has been changed to `double?`.
* The obsolete `IModel.CreateMemberAttributeSetAsync` method overload has been removed.
* The interface `IFlatBar` has been removed (use `IBar` instead).
* `Crane` value has been added to `LoadcaseType` enumeration.
* The `IPortalFrame.AutoDesign` property has been made obsolete and will be removed in version 27.0.0.
