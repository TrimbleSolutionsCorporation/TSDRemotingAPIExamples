# Release notes

This document contains the notes for individual releases of the _TeklaStructuralDesigner.RemotingAPI_ NuGet package for major version 26.

## Version 26.2.0

* A bug causing the `MemberSpanInfo` to fail to identify the correct member span in some cases has been fixed.
* The method `IDesignCondition.GetResult` has been made obsolete and will be removed in version 28.0.0.
  * The method always returned either `CheckStatus.Pass` or `CheckStatus.Fail` and did not provide any additional information.
  * The recommended alternative is to use the `IDesignCondition.GetStatus` and check for `DesignStatus.Actual` (or `DesignStatus.Failed` respectively).
* A new method `ILoadcase.GetGeneratedWindDataAsync` has been added that allows users to retrieve the generated wind data for a loadcase.

## Version 26.1.0

This version was skipped due to no changes.

## Version 26.0.1

* The type of the property `MinorAxisElasticSectionModulus` of `IColdRolledSectionBase` has been changed to `double?`.
* The obsolete `IModel.CreateMemberAttributeSetAsync` method overload has been removed.
* The interface `IFlatBar` has been removed (use `IBar` instead).
* `Crane` value has been added to `LoadcaseType` enumeration.
* The `IPortalFrame.AutoDesign` property has been made obsolete and will be removed in version 27.0.0.
